# Café Fontenebleau

Responsive multi-page website developed for a fictional café and restaurant.

The project was created as a front-end study focused on responsive layouts, multi-page website architecture, navigation, asset organization and user interface structure.

---

##  Live Demo

🌐 https://wellingtonamerico.github.io/Cafe-Fontenebleau/

---

##  Project Overview

The website simulates the online presence of a fictional café and restaurant, with multiple pages organized around different sections of the business.

The project focuses on building a consistent user experience across pages while maintaining a responsive layout for different screen sizes.
